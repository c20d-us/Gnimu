# Gnimu v2: timer-driven GNSS+IMU telemetry

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE)
[![Platform: ESP32 / nRF52840](https://img.shields.io/badge/platform-ESP32%20%2F%20nRF52840-000000.svg)](#status)

Gnimu v2 is the next iteration of [Gnimu](https://github.com/c20d-us/Gnimu), firmware that turns a microcontroller, a u-blox GNSS module and an IMU into a low-latency motorsports telemetry source. It is being rebuilt around a timer-driven scheduling model, drawing on lessons from the original Gnimu, its halted multi-protocol output work, and the Gnimu-NG rewrite.

The name is pronounced "nigh-mew."
