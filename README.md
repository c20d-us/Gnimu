# Gnimu: GNSS+IMU motorsports telemetry

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE)
[![Platform: ESP32 / nRF52840](https://img.shields.io/badge/platform-ESP32%20%2F%20nRF52840-000000.svg)](#variants)
[![Language: C++ (Arduino)](https://img.shields.io/badge/language-C%2B%2B%20(Arduino)-00599C.svg)](https://www.arduino.cc/)

Gnimu v2 is the next iteration of [Gnimu](https://github.com/c20d-us/Gnimu), firmware that turns a microcontroller, a u-blox GNSS module and an IMU into motorsports telemetry source. It is being rebuilt around a timer-driven scheduling model, drawing on lessons from the original Gnimu.

The name is pronounced "nigh-mew."
